📂 FileSystem Organizer (Python)
Этот скрипт на Python помогает автоматически наводить порядок в папке Загрузки (Downloads). Он сканирует файлы и распределяет их по категориям и датам.

✨ Что делает этот код:
Сортировка по типам: Разносит файлы в папки: Images, Videos, Documents, Archives и Python.

Группировка по датам: Внутри каждой категории создаются подпапки формата ГГГГ-ММ (например, 2024-05), основываясь на дате создания файла.

Автоматизация: Вам не нужно создавать папки вручную — скрипт сделает это сам (используя os.makedirs).

Удобство: После завершения работы на Windows скрипт автоматически открывает папку с результатом.

🛠 Технологии:
Python 3.x

Модули: os, shutil, platform, datetime.

🚀 Как запустить:
Убедитесь, что у вас установлен Python.

Скачайте файл fileSystem.py.

Запустите его через терминал:

Bash
python fileSystem.py
Наслаждайтесь чистой папкой «Загрузки»!
