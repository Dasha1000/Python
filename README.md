> Автоматический скрипт на Python для наведения порядка в папке загрузок.

---

### 🚀 Основные возможности
* **Умная сортировка**: распределяет файлы по категориям (Images, Videos, Documents и др.).
* **Архивация по датам**: создает подпапки вида `ГГГГ-ММ` для удобного поиска.
* **Кроссплатформенность**: работает на Windows, macOS и Linux.
* **Авто-открытие**: на Windows сразу открывает папку после завершения работы.

---

### 🛠 Инструменты
`Python 3.x` | `shutil` | `os` | `datetime`
